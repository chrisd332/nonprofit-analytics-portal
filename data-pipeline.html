💡 Database Layer Alignment

This page documents the technical schema layer powering nonprofit_dw. Raw data enters through the staging schema before being transformed into normalized fact and dimension structures for executive reporting.

Expanded Star Schema Architecture (nonprofit_dw)

To support multi-dimensional reporting across fundraising, volunteer efforts, and program impact, our ELT pipeline aggregates raw operational sources from staging into unified warehouse tables:

Staging Ingestion

  • staging.stg_raw_donors_giving
  • staging.stg_raw_resource_distribution

Warehouse Fact Tables

  • fact_donations
  • fact_resource_distribution
  • fact_volunteer_activity

Warehouse Dimension Tables

  • dim_donors
  • dim_hubs
  • dim_campaigns
  • dim_resources

Automated API Data Pipeline Workflow

1. Extraction: Raw CSV uploads and API webhooks land directly into the PostgreSQL staging schema.
2. Transformation: Automated scripts clean null values, normalize date formats, and compute key metrics (like CPDR and labor values).
3. Serving Layer: The lightweight PHP PDO API (api/get_dashboard_data.php) fetches query results and serves formatted JSON payloads directly to Chart.js and frontend tables.
