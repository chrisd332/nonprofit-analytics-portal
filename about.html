System Overview & User Guide

A comprehensive guide detailing the purpose, architecture, and operational data pipelines behind the portal.

💡 What Is This System?

The Nonprofit Executive Analytics Portal provides non-profit leaders with real-time visibility into donor contributions, volunteer human capital, and physical aid distribution through a single, cohesive dashboard. Nonprofits often struggle with fragmented donor systems (CRM) and payment processing gateways. This portal unifies those sources into actionable business intelligence.

Operating behind the web portal is a normalized database architecture (ELT data pipeline) that automatically ingests uncleaned transaction logs and transforms them into star-schema analytics tables.

Core Portal Modules

Executive Dashboard

Real-time KPI metrics tracking gross monetary raised, active donor count, volunteer labor economic value, and distribution throughput.

Executive Insights

Automated word-based narrative findings dynamically evaluated based on active dashboard filter states and KPI shifts.

Data Warehouse Hub

Technical documentation detailing source-to-target ELT workflows, staging schemas, dbt transformation pipelines, and relational ERDs.

My Account & Org

Tenant account settings displaying active organization IDs, subscription tiers, and row-level data isolation parameters.

Architecture & Multi-Tenancy

This portal is built for enterprise micro-SaaS deployment. Every query executed via api/get_dashboard_data.php is strictly scoped by the authenticated user's org_id session variable.

Volunteer labor values are dynamically evaluated using Independent Sector national standards ($31.80/hour), giving executives instantly verifiable metrics for grant reporting and auditing.

Commercial & Marketplace Readiness

Engineered specifically for clean asset transfer on micro-acquisition platforms like Acquire.com and Flippa, the codebase follows strict modular standards with zero complex cloud lock-in.

The built-in self-service tenant registration and onboarding loop allow the platform to operate fully autonomously as a scalable B2B SaaS business.

Security & Data Isolation

Data privacy is enforced at the database query level. Using strict PDO prepared statements, parameterized queries eliminate SQL injection vectors while session tokens guard against unauthorized endpoint probing. Multi-tenant partitioning guarantees organization data remains strictly segregated.
